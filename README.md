
# 📊 Análise de Dados — Python e Dashboard

## 📌 Sobre o projeto

Este repositório reúne exercícios práticos desenvolvidos durante meus estudos de Análise de Dados, incluindo o **Dashboard Final**, com foco na análise de diversidade e características profissionais.

O projeto explora dados relacionados ao nível de escolaridade, faixa etária, gênero e níveis de senioridade profissional (Júnior, Pleno e Sênior), buscando facilitar a visualização e a compreensão dessas informações.

## 🎯 Objetivos

- Aplicar conhecimentos práticos de análise de dados.
- Organizar informações para facilitar a interpretação.
- Explorar características demográficas e profissionais por meio de visualizações.
- Desenvolver habilidades de análise e apresentação de dados.

## 🛠️ Tecnologias e ferramentas

- **Python:** utilizado nos exercícios práticos de análise de dados.
- **Jupyter Notebook:** ambiente utilizado para desenvolver e documentar os exercícios em Python.
- **Looker Studio (Google Data Studio):** ferramenta utilizada para criar o Dashboard Final e visualizar os dados.

A análise contempla as seguintes dimensões:

- **Escolaridade:** distribuição dos níveis de formação acadêmica.

O projeto aplica conceitos de visualização de dados para facilitar a leitura e a interpretação das informações apresentadas.
